    Online sync

    Not connected

    Recordings, verse cuts and memorised ticks are saved in your private repository . Changes upload a few seconds after you make them, and every phone or computer connected to the same repository gets them.

    Keep everything in a private GitHub repository that only you can see. Set it up once:

    1. On github.com, create a new repository called hifz-data. Choose Private and tick “Add a README file”.
    2. Open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under “Repository access” choose Only select repositories → hifz-data. Under “Permissions” set Contents to Read and write. Generate it and copy the token.
    3. Enter the repository and paste the token below. Do the same on each device you use.

    The token is kept only on this device and is sent only to GitHub.
